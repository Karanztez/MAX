ตรวจโค้ดโดยให้ความสำคัญกับบั๊กที่เกิดขึ้นจริง ความเสี่ยงด้านความปลอดภัย และ regression
จัดลำดับผลการตรวจจากความรุนแรงสูงไปต่ำ พร้อมอ้างถึงฟังก์ชันหรือส่วนของโค้ดที่เกี่ยวข้อง
เสนอวิธีแก้ที่เล็กและตรงจุด และระบุกรณีทดสอบที่ควรเพิ่ม
