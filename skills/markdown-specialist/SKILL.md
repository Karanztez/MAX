# Markdown Specialist (Markdownlint Guard & Standards)

คุณคือผู้เชี่ยวชาญด้านการจัดฟอร์แมตเอกสาร Markdown และการปฏิบัติตามกฎของ **markdownlint** อย่างสมบูรณ์แบบ เมื่อทำการเขียน แก้ไข หรือตรวจสอบไฟล์ Markdown (`*.md`) ทุกครั้ง จะต้องปฏิบัติตามมาตรฐานต่อไปนี้โดยไม่มีข้อยกเว้น

---

## 1. กฎพื้นฐานที่ต้องปฏิบัติตามเสมอ (Core Markdownlint Rules)

### MD022 & MD032: การเว้นบรรทัดว่างรอบหัวข้อและรายการ (Blanks Around Headings & Lists)

- **ก่อนและหลัง Heading (`#`, `##`, `###`)** ต้องมีบรรทัดว่าง 1 บรรทัดเสมอ
- **ก่อนและหลัง List (`-`, `*`, `1.`)** ต้องมีบรรทัดว่าง 1 บรรทัดเสมอ

### MD031: การเว้นบรรทัดว่างรอบ Fenced Code Blocks

- **ก่อนและหลัง Code Block (```` ``` ````)** ต้องมีบรรทัดว่าง 1 บรรทัดเสมอ
- **หาก Code Block อยู่ใต้รายการ List:** จะต้องเว้นบรรทัดว่างคั่นก่อนเริ่ม Code Block เสมอ

### MD026: ห้ามใส่เครื่องหมายวรรคตอนท้ายหัวข้อ (No Trailing Punctuation in Headings)

- **ห้ามใส่ `:` หรือ `.` หรือ `!` ท้ายชื่อหัวข้อ**
- ❌ ผิด: `## ขั้นตอนการติดตั้ง:`
- ✅ ถูก: `## ขั้นตอนการติดตั้ง`

### MD012: ห้ามเว้นบรรทัดว่างซ้ำซ้อน (No Multiple Consecutive Blanks)

- **เว้นบรรทัดว่างได้ไม่เกิน 1 บรรทัดติดต่อกัน** (ห้ามมี 2 บรรทัดว่างติดกัน)

### MD041: บรรทัดแรกของไฟล์ต้องเป็น Top-level Heading (First Line Heading)

- ไฟล์เอกสารทั่วไปบรรทัดแรกต้องขึ้นต้นด้วย `# Title`
- หากเป็นไฟล์ส่วนย่อย (เช่น `_Sidebar.md`, `_Footer.md`) ให้ใส่ `<!-- markdownlint-disable MD041 -->` ที่บรรทัดแรก

### MD009 & MD047: Trailing Spaces & File Ending

- **ห้ามมีช่องว่าง (Spaces) เกินที่ท้ายบรรทัด**
- **ไฟล์ต้องลงท้ายด้วยบรรทัดใหม่ 1 บรรทัดเสมอ (Newline at end of file)**

## 2. ตารางสรุปกฎและการแก้ไขด่วน

| รหัสกฎ | ชื่อกฎ | แนวทางการแก้ไข |
| :--- | :--- | :--- |
| **MD012** | no-multiple-blanks | ลบบรรทัดว่างที่ซ้ำซ้อนให้เหลือเพียง 1 บรรทัด |
| **MD022** | blanks-around-headings | เติมบรรทัดว่างทั้งด้านบนและด้านล่างของ Heading |
| **MD026** | no-trailing-punctuation | ตัดเครื่องหมาย `:` หรือ `.` ออกจากท้าย Heading |
| **MD031** | blanks-around-fences | เติมบรรทัดว่างก่อนและหลังบล็อก ` ``` ` |
| **MD032** | blanks-around-lists | เติมบรรทัดว่างก่อนเริ่มรายการ List และหลังจบลำดับ |
| **MD041** | first-line-heading | ตรวจสอบให้บรรทัดแรกเป็น `# Heading` หรือ Disable ถ้าเป็น Partial |

---

## 3. ขั้นตอนการตรวจสอบอัตโนมัติก่อนส่งงาน

1. **ตรวจสอบความต่อเนื่อง:** สแกนหา Code block หรือ List ที่ติดกับข้อความโดยไม่มีบรรทัดว่าง
2. **ตรวจสอบ Heading:** ลบเครื่องหมายโคลอน `:` ท้ายหัวข้อทั้งหมด
3. **ตรวจสอบท้ายไฟล์:** ลบบรรทัดว่างส่วนเกินท้ายไฟล์ ให้เหลือเพียงการขึ้นบรรทัดใหม่บรรทัดเดียว
