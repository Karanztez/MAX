# 🛡 Web Domain Security Guard

เพื่อป้องกันไม่ให้ AI เข้าถึงเว็บไซต์ที่ไม่พึงประสงค์ แอบส่งข้อมูลออกภายนอก หรือดึงเนื้อหาจากเว็บอันตราย **MAX** มีระบบรักษาความปลอดภัย **Interactive Web Domain Guard**

---

## 1. วิธีการทำงานของระบบคัดกรองเว็บ

เมื่อ AI เรียกใช้เครื่องมือ `fetch_web_content`, `search_web` หรือ `http_request` ไปยัง URL ภายนอก ระบบจะตรวจสอบว่าโดเมนนั้นอยู่ในรายชื่อที่อนุญาตแล้วหรือไม่:

1. **หากเคยอนุญาตไว้แล้ว:** AI จะดึงข้อมูลได้ทันทีโดยไม่ขัดจังหวะผู้ใช้
2. **หากเป็นโดเมนใหม่:** ระบบจะหยุดรอและแสดงข้อความถามผู้ใช้บน Terminal หรือ GUI:
   ```text
   🛡️ [ความปลอดภัย] AI ต้องการเข้าถึงเว็บไซต์ภายนอก:
   👉 URL: https://api.github.com/repos/Karanztez/MAX
   👉 โดเมน: api.github.com

   กรุณาเลือกตัวเลือก:
   [1] ยอมรับครั้งนี้ (Allow Once)
   [2] ไม่ยอมรับ (Deny)
   [3] ยอมรับโดเมนนี้เสมอ (Always Allow Domain)
   [4] ยอมรับทุกโดเมน (Allow All - ไม่แนะนำ)
   ```

---

## 2. การจัดการรายชื่อโดเมนที่อนุญาต (Managing Allowed Domains)

คุณสามารถพิมพ์คำสั่งต่อไปนี้ในห้องแชท:
- `/security` หรือ `/domains` — ดูรายชื่อโดเมนทั้งหมดที่เคยอนุญาตไว้
- `/domains remove <domain>` — ลบโดเมนที่ไม่ต้องการออกจากรายการอนุญาต
- `/domains clear` — รีเซ็ตรายชื่อโดเมนทั้งหมด
